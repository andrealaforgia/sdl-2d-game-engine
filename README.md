# SDL 2D Game Engine

A lightweight, modular 2D game engine built with C and SDL2, designed for creating retro-style games and platformers.

## Features

### Graphics
- **A window from one config** (`graphics_config_t`: title, size, window mode, vsync, logical view height)
- **A view of fixed height whose width follows the window** (`begin_frame` fits it), so wide windows show more world instead of bars
- **One sprite call**, `render_sprite`: float destination, flip, alpha, rotation and tint (`draw_options_t`)
- **Textures** from image files or from pixels, smooth or crisp per texture
- **Primitive rendering** (lines, circles, polygons, float-precision filled rectangles with alpha)
- **Built-in 5x7 pixel font** in any colour and scale, and an asset-based bitmap font
- **TTF text** (optional: `make WITH_TTF=0` builds without SDL2_ttf)
- **Frame capture** to BMP (`save_frame_bmp`), for snapshots and tests
- **Frame rate management**, FPS tracking, multiple window modes

### Input
- **Controls**: buttons are bits of a mask each game defines; `controls_t` tracks held and pressed (edge) state with no timers
- **Key bindings**: a table of scancodes per button, read with `keyboard_read`
- **Events** (quit handling) and **mouse** support

### Math
- **Seedable RNG** (`rng_t`); the random geometry helpers take the generator, nothing is global
- **Vectors, points, float rectangles**, `clampf`, `lerpf`, `approachf`, overlap tests
- **Fixed-step planning** (`stepper_plan`) so physics is stable at any frame rate

### Audio
- **A software mixer**: mono 16-bit samples at `MIXER_RATE`, whether decoded from WAV files (any SDL-readable format is converted) or generated by the game (`set_sound`)
- **Music** through a callback the game provides, with its own gain and switch; sound effects have their own switch and a master volume
- Works without a sound device, and `audio_render` can be driven by hand in tests

### Utilities
- **Command line**: the engine's options plus the game's own (flag, int, float, string), one parser and one `--help`
- **Object pool** with walking (`pool_next_active`) and release by pointer
- **Event system** (publish and subscribe)
- **Logging**, **clock** (milliseconds and a high-resolution seconds clock), **types**

## Usage

This engine is designed to be used as a **Git submodule** in your game projects.

### Adding to a New Project

```bash
# Create your game project
mkdir my-game
cd my-game
git init

# Add the engine as a submodule
git submodule add git@github.com:andrealaforgia/sdl-2d-game-engine.git engine

# Create your game structure
mkdir -p game/src/main
mkdir -p assets
```

### Makefile Integration

Add the engine directories to your Makefile:

```makefile
CC = gcc
SDL2_CFLAGS := $(shell sdl2-config --cflags)
SDL2_LFLAGS := $(shell sdl2-config --libs) -lSDL2_image -lSDL2_ttf

ENGINE_GRAPHICS_DIR = engine/core/graphics
ENGINE_MATH_DIR = engine/core/math
ENGINE_INPUT_DIR = engine/core/input
ENGINE_AUDIO_DIR = engine/core/audio
ENGINE_TIME_DIR = engine/core/time
ENGINE_UTILS_DIR = engine/core/utils
ENGINE_MEMORY_DIR = engine/core/memory
ENGINE_EVENTS_DIR = engine/core/events

GAME_MAIN_DIR = game/src/main

SRC = $(wildcard $(ENGINE_GRAPHICS_DIR)/*.c) \
      $(wildcard $(ENGINE_MATH_DIR)/*.c) \
      $(wildcard $(ENGINE_INPUT_DIR)/*.c) \
      $(wildcard $(ENGINE_AUDIO_DIR)/*.c) \
      $(wildcard $(ENGINE_TIME_DIR)/*.c) \
      $(wildcard $(ENGINE_UTILS_DIR)/*.c) \
      $(wildcard $(ENGINE_MEMORY_DIR)/*.c) \
      $(wildcard $(ENGINE_EVENTS_DIR)/*.c) \
      $(wildcard $(GAME_MAIN_DIR)/*.c)

INCLUDES = -I$(ENGINE_GRAPHICS_DIR) -I$(ENGINE_MATH_DIR) \
           -I$(ENGINE_INPUT_DIR) -I$(ENGINE_AUDIO_DIR) \
           -I$(ENGINE_TIME_DIR) -I$(ENGINE_UTILS_DIR) \
           -I$(ENGINE_MEMORY_DIR) -I$(ENGINE_EVENTS_DIR) \
           -I$(GAME_MAIN_DIR)

CFLAGS := -std=c99 -Wall -Wextra $(INCLUDES) $(SDL2_CFLAGS)
LFLAGS := $(SDL2_LFLAGS) -lm

OBJ = $(SRC:.c=.o)
TARGET = my-game

all: $(TARGET)

$(TARGET): $(OBJ)
	$(CC) -o $@ $^ $(LFLAGS)

%.o: %.c
	$(CC) $(CFLAGS) -c -o $@ $<

clean:
	rm -f $(OBJ) $(TARGET)
```

## API Overview

### Window, view and drawing

```c
graphics_config_t config = default_graphics_config("My Game");
config.view_height = 544.0f;  // draw in units: always this tall, as wide as the window allows
graphics_context_t graphics = initialize_graphics_context(&config);

begin_frame(&graphics, 0, 0, 0);          // fits the view; graphics.view_width, view_scale
texture_t sprite = load_texture(graphics.renderer, "hero.png");
draw_options_t flipped = {true, 1.0f, 0.0f, false, 0, 0, 0};
render_sprite(&graphics, &sprite, NULL, make_frect(10, 20, 64, 64), &flipped);
draw_filled_rect_alpha(&graphics, 0, 0, 200, 40, COLOR(10, 10, 30), 140);
pixel_font_t font = build_pixel_font(&graphics);
render_pixel_text(&font, &graphics, 14, 8, "SCORE 000100", 3.0f, 255, 240, 120);
present_frame(&graphics);
```

### Input

```c
enum { BTN_LEFT = 1u << 0, BTN_JUMP = 1u << 1 };
static const key_binding_t bindings[] = {
    {BTN_LEFT, {SDL_SCANCODE_LEFT, SDL_SCANCODE_A, 0, 0}},
    {BTN_JUMP, {SDL_SCANCODE_SPACE, SDL_SCANCODE_UP, 0, 0}},
};
controls_t controls = {0};
controls_update(&controls, keyboard_read(bindings, 2));
if (controls_pressed(&controls, BTN_JUMP)) { /* went down this frame */ }
if (controls_held(&controls, BTN_LEFT)) { /* still down */ }
```

### Audio

```c
audio_context_ptr audio = init_audio_context(max_sounds, 128);
load_sound(audio, 0, "assets", "jump.wav");        // or: set_sound(audio, 1, samples, frames)
play_sound(audio, 0);
set_music_source(audio, my_music_fn, &my_music);   // fills int16 samples scaled by a gain
set_music_enabled(audio, false);                   // M toggles the music
set_sound_enabled(audio, false);                   // S toggles the effects
```

### Time, random numbers, pools and events

```c
rng_t rng; rng_seed(&rng, 42);
point_t p = random_point(&rng, width, height);

double step;
int steps = stepper_plan(frame_seconds, 1.0 / 120.0, 0.1, &step);

object_pool_t bullets = create_object_pool(sizeof(bullet_t), 16);
size_t cursor = 0;
for (bullet_t* b; (b = pool_next_active(&bullets, &cursor));) {
  if (b->life <= 0) pool_release_object(&bullets, b);
}

event_system_t events = create_event_system();
subscribe(&events, EVENT_SHOT, on_shot, audio);
publish(&events, &(game_event_t){EVENT_SHOT, &x, sizeof(x)});
```

### Command line

```c
const custom_option_t custom[] = {
    {"seed", OPTION_INT, &seed, "the random seed"},
    {"title", OPTION_FLAG, &show_title, "start on the title screen"},
};
command_line_options_t options = default_command_line_options();
options.window_mode = WINDOWED;                    // a game's own defaults
parse_command_line_options(argc, argv, &options, custom, 2);
if (options.help) print_help(&options, custom, 2); // --seed=7 --title --vsync ...
```

## Development

### Code Quality
The project maintains high code quality standards:

```bash
# Check code style
make lint

# Auto-format code
make format

# Build library
make all

# Clean build artifacts
make clean
```

### Code Standards
- **C99 standard** with strict compiler warnings
- **Google C++ style guide** (adapted for C)
- **Header include order**: Own header, system headers, local headers
- **Line length**: Maximum 80 characters
- **Header guards**: `CORE_MODULE_FILENAME_H_` format

## Automated checks

`make test` runs focused C contract tests with a controlled clock and injected
allocation failures. `make sanitize` runs the same tests with AddressSanitizer
and UndefinedBehaviourSanitizer. Python 3 and the SDL libraries are required;
the checks do not create a window or run an interactive application.
